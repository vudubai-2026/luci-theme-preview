# LuCI Theme Preview V2.6

Hệ thống tự động dựng môi trường OpenWrt giả lập phần cứng **Xiaomi Mi Router CR6608** (MediaTek MT7621, RAM 256MB), tự động nhận diện/giải nén theme LuCI (Source, Rootfs Overlay, `.ipk`), chụp ảnh chuẩn **Retina 2x** và xuất bản **Interactive Sandbox** lên GitHub Pages.

🌐 **Trang tổng hợp tất cả Preview:** /

## Cách sử dụng
1. Mở tab **Actions** $\rightarrow$ chọn **Preview LuCI themes V2.6 (Link-Only · Auto-README)**.
2. Bấm **Run workflow**, dán link GitHub của theme cần test (ví dụ: `jerrykuku/luci-theme-argon` hoặc `peditx/luci-theme-peditx`).
3. Chờ hoàn tất, bảng bên dưới sẽ tự động cập nhật kết quả mới nhất.
