# LuCI Theme Preview V2.5

Hệ thống tự động dựng môi trường OpenWrt giả lập phần cứng **Xiaomi Mi Router CR6608** (MediaTek MT7621, RAM 256MB), tự động nhận diện/giải nén theme LuCI (hỗ trợ Source, Rootfs Overlay và `.ipk`), chụp ảnh **Retina 2x** và xuất bản **Interactive Sandbox** lên GitHub Pages.

## Cách dùng
1. Vào tab **Actions** -> chọn **Preview LuCI themes V2.5**.
2. Bấm **Run workflow**, nhập link GitHub của theme cần test (ví dụ: `jerrykuku/luci-theme-argon` hoặc `peditx/luci-theme-peditx`).
3. Xem kết quả và trải nghiệm giả lập trực tiếp trên trang GitHub Pages.
